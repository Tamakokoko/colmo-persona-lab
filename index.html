从本地网页到分享链接

Git 保存版本，GitHub 存放代码，GitHub Pages 把它变成可访问的网页。

  1. 在 GitHub 新建仓库，例如 colmo-persona-lab。
  2. 用 Add file → Upload files 上传网页文件夹内的文件，确保 index.html 位于仓库根目录。
  3. 在 Settings → Pages 中选择 Deploy from a branch → main → / (root)，保存后等待生成访问链接。

发布的是文件中的默认值。工作坊里编辑的参数只保存在本机；请导出 JSON 交给其他人导入。发布前确认仓库与网页的可见范围。
